# USHLINX | Website Corporativo & Soluciones Tecnológicas

Sitio web corporativo moderno, ultra-responsive y optimizado para **GitHub Pages**. Desarrollado con las mejores prácticas de **UX/UI Mobile-First**, HTML5 semántico, CSS3 modular (con variables y glassmorphism) y JavaScript Vanilla optimizado sin dependencias externas pesadas.

---

## 🌟 Características Principales

- 📱 **Diseño UX/UI Mobile-First & Ultra Responsive**: Adaptabilidad fluida desde smartphones hasta pantallas 4K.
- 🌓 **Selector de Tema Claro / Oscuro**: Persistencia en `localStorage` con adaptación al sistema operativo.
- 🧮 **Cotizador Estimativo Interactivo de Proyectos**: Calculador en tiempo real de presupuestos corporativos con opción de autocopiado al formulario de contacto.
- ⚡ **Animación de Métricas en Tiempo Real**: Animación progresiva mediante `IntersectionObserver`.
- 🔍 **SEO de Grado Empresarial**: Meta etiquetas Open Graph, favicons y marcado de datos estructurados `Schema.org (JSON-LD)`.
- ♿ **Accesibilidad A11y & Performance**: Etiquetas ARIA, contraste visual adecuado y navegabilidad mediante teclado.
- 📩 **Formulario de Contacto Interactivo con Notificaciones Toast**: Validación en tiempo real y retroalimentación inmediata al usuario.
- 📦 **Listo para GitHub Pages**: Incluye archivo `.nojekyll` para despliegue directo e instantáneo.

## 🚀 Cómo Desplegar en GitHub Pages

Para publicar este sitio web en **GitHub Pages**:

1. **Crear o Subir los cambios a tu repositorio de GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - USHLINX Corporate Website"
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/git-ushlinx.git
   git push -u origin main
   ```

2. **Activar GitHub Pages**:
   - En tu repositorio de GitHub, ve a **Settings** (Configuración) > **Pages**.
   - En **Source** (Fuente), selecciona la rama `main` y la carpeta `/ (root)`.
   - Haz clic en **Save** (Guardar).

3. **¡Listo!**: En pocos minutos tu sitio estará en vivo en `https://TU-USUARIO.github.io/git-ushlinx/`.
